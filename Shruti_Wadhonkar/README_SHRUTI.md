# Contribution: Shruti Wadhonkar (Validation & UI Styling Lead)

## Owned Components
1. **`Customer.java`**: Domain model storing customer details (`name`, `phone`).
2. **Customer Input Validation**: Strict verification preventing blank names and regex checking for valid 10-digit Indian mobile numbers (`\d{10}`).
3. **`style.css`**: The complete commercial luxury CSS design system:
   - Burgundy, Deep Wine, Peach & Cream brand color tokens (`#59171B`, `#26070A`, `#FED7B8`, `#FBF0E8`, `#DAEBE3`, `#D4AF37`, etc.).
   - Header location pill and city selection dropdown styling.
   - Movie poster card zoom effects, certification badges, and quick trailer buttons.
   - Screen projector ambient glow curvature with subtle top border projection.
   - Interactive 10x12 seat button styling and animated transitions (Available, Selected, Booked).
   - Cinema Concessions drawer cards with quantity increment/decrement controls.
   - Promo Code input styling with validation feedback colors (success green / error red).
   - Golden & Burgundy Digital Boarding Pass with circular punch cuts, perforated tear line, and QR code wrap.
   - Responsive 16:9 video trailer modal overlay with blur backdrop.
   - Print stylesheet (`@media print`) isolating only the Boarding Pass for clean PDF/paper printing.

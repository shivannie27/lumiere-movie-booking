# Contribution: Shruti Wadhonkar (Validation & UI Styling Lead)

## Owned Components
1. **`Customer.java`**: Domain model storing customer details (`name`, `phone`).
2. **Customer Input Validation**: Strict verification preventing blank names and regex checking for valid 10-digit Indian mobile numbers (`\d{10}`).
3. **`style.css`**: The complete CSS design system:
   - Burgundy & Peach brand color tokens (`#59171B`, `#FED7B8`, `#FBF0E8`, `#DAEBE3`, etc.).
   - Interactive 10x12 seat button styling and states (Available, Selected, Booked).
   - Responsive movie card layout with image zoom effects.
   - Modal receipts and dashboard analytics cards.

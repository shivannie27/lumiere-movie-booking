# Contribution: Shaikh Rahim (Movie Catalog & Frontend Layout Lead)

## Owned Components
1. **`Movie.java`**: Domain model storing movie information (`title`, `language`, `genre`, `durationMinutes`, `price`, `rating`, `poster`).
2. **`index.html`**: The entire frontend HTML structure, screen router containers, hero banner, movie cards layout, interactive cinema and showtime pills, seat matrix view, and modal templates.
3. **`posters/`**: Official theatrical poster collection for all 8 featured movies (Dune 2, Deadpool & Wolverine, Inside Out 2, Oppenheimer, Kalki 2898 AD, Laapataa Ladies, Maharaja, Furiosa).
